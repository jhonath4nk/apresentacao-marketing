# Apresentação — Marketing, Comercial e BI

Portfólio e proposta comercial de Jhonathan Kern para gestão integrada de marketing, operação comercial e Business Intelligence.

## Site público

https://jhonathan-kern-marketing.jhonathankern.chatgpt.site

## Estrutura

- `index.html`: versão publicada da apresentação.
- `assets/`: estilos, scripts, fontes e imagem principal.
- `clients/`: marcas atendidas na proposta.

## Visualização local

O projeto é estático. Na pasta do repositório, execute:

```bash
python -m http.server 8080
```

Depois abra `http://localhost:8080`.

## Atualizações

As alterações futuras devem manter sincronizados o repositório e a versão pública do site.
